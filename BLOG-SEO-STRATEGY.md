# Boise Cabinet Co — Blog SEO/AEO/GEO Strategy (50 Posts)

_Built from Ahrefs keyword research (US, pulled 2026-07-11). Goal: become the definitive
cabinetry resource in the Treasure Valley and win SEO + AEO (answer engines) + GEO (generative
engines) across the homeowner buying journey._

## Strategic thesis

Local cabinet search volume in Boise is low (e.g. `kitchen remodel boise` ~250/mo,
`kitchen cabinets boise` ~70, `custom cabinets boise` ~30). Ranking only for local terms caps
upside. So we run **two tracks**:

1. **National informational authority** — the large, real demand: costs, painting/refacing,
   door styles, colors, materials, sizes, organization, bathroom vanities (`bathroom vanity`
   97k), pantries (`pantry cabinet` 53k), maintenance. These pages earn topical authority and
   get cited by AI Overviews/ChatGPT/Perplexity (AEO/GEO), and they rank for the long tail.
2. **Treasure Valley GEO cluster** — local-intent posts + local framing woven into national
   posts, all internally linked to existing service/room/location pages for conversion.

Every post: **Answer-First** (a 40–60 word direct answer in the first 100 words, wrapped for a
featured-snippet/`speakable`), 1,600+ words, proper H1→H2→H3, comparison tables, checklists,
callouts (sage), an FAQ block with `FAQPage` schema, `BlogPosting` + `BreadcrumbList` schema,
strong internal links, 1+ external authority citation (e.g. NKBA, Forbes Home, HomeAdvisor cost
data), a unique optimized WebP featured image, and a soft CTA to the estimator/consultation.

## Chosen approach (client decision, 2026-07-11)

**Two phases:** (1) **Upgrade all ~58 existing posts** to this quality bar (rich 1,600+ word
custom HTML replacing the thin factory `buildClusterPost` output, Answer-First, sage callouts,
tables, checklists, FAQ, schema, deeper internal links). (2) **Add 50 net-new posts** from the
Ahrefs plan above (deduped against existing slugs). ~108 premium posts total.

**Images:** unique **AI-photorealistic** featured image per post, never reused.

## Image pipeline (requires OPENAI_API_KEY)

The repo already has the pipeline: `scripts/generate-blog-images.mjs` → OpenAI Images API
(DALL·E 3) → `public/images/blog/{slug}.png`, then `images:optimize` / `images:variants` /
`images:blur` → WebP + responsive variants + LQIP. Steps per post:

1. Add a hand-crafted, on-brand DALL·E prompt for the slug to `scripts/blog-image-prompts.json`
   (warm Treasure-Valley cabinetry, brand palette cues, photoreal, no text/logos).
2. Add the slug → image entry in `scripts/generate-blog-image-registry.mjs` ENTRIES, then
   `node scripts/generate-blog-image-registry.mjs` to regenerate `shared/blogImageRegistry.ts`.
3. With `OPENAI_API_KEY` set: `npm run images:generate -- <slug>` then `npm run images:optimize`.

> **Blocker:** image generation needs the client's `OPENAI_API_KEY` (in `.env.local` locally or
> Replit Secrets). Content + prompts are authored regardless; images batch-generate once the key
> is present.

## How to add/upgrade a post (build-safe)

- Premium posts live as full `BlogPostData` objects (rich `content` HTML) in
  `shared/content/premiumPosts.ts` (new), spread into `shared/content/allBlogPosts.ts`.
- Upgrades: move an existing slug's entry to a full `BlogPostData` with custom `content`
  (replacing its factory call), keeping the same slug (preserves URL/SEO).
- Register in `shared/contentHubs.ts` `CONTENT_MANIFEST`; validate with
  `npx tsx scripts/verify-content.ts` (needs ≥5 H2, ≥5 internal links, 6–15 FAQs, ≥1 city, 75–3500 words).

## Production cadence

Batches of ~6–8 posts per working session (content + image prompts + wiring + validation),
**upgrades first** (highest existing-SEO leverage), then net-new pillars, then supporting posts.
