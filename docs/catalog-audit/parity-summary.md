# Supplier Catalog Parity — Summary

Generated by the Supplier Catalog Parity pass. Goal: `data/catalog.json`, its
generated output, and the catalog imagery match the One Source `Custom_Catalog.v1.pdf`
and onesourcecabinets.com exactly, while keeping Boise Cabinet Co branding (no
"One Source"/"OSC"/"Reserve" in customer-facing output).

## Deviations fixed

1. **Fabricated drawer-slide load rating.** `app/hardware/page.tsx` advertised
   "100 lb rated" slides; the supplier catalog states no load rating. Removed the
   claim and the `loadRatingLbs` field from `data/supplier-catalog/hardwareSpec.json`.
2. **Edge-banding spec.** Construction feature said "PUR edge banding"; the PDF
   specifies "1MM MATCHING EDGEBANDING". Corrected in
   `data/supplier-catalog/construction.json`.
3. **Finish swatch imagery.** The prior "real" swatches were flat color tiles
   (even woodgrains). Replaced with authentic supplier swatches: high-DPI label-
   anchored crops from the PDF for 254 finishes, and cleaned website photos for 45.
   The last 3 ambiguous labels (Rialto, Hemlock, Nizza Riva) were hand-cropped
   from PDF p51/p66 — every finish now has a real swatch (299/299).
4. **Product imagery.** The prior cabinet/door imagery was app-generated. Wired
   in the supplier's own line drawings: 6/6 door profiles (PDF p8-9) and 355/382
   cabinet SKUs mapped to their family isometric renderings (PDF p82-123), stored
   under `public/images/catalog/{door-styles,renderings}/` and resolved by codegen.

## Residual (not provably matched — 27 cabinet SKUs, image only)

27 cabinet SKUs have no dedicated isometric line drawing in the supplier PDF
(e.g. glass-wall, some floating variants, trim/filler/panel items). These fall
back to a spec-accurate front-elevation SVG diagram. Their names and dimensions
are verified against the PDF; only the rendering is generated.

## How to re-verify

```
npm run catalog:inventory          # SKU diff + gaps
node scripts/catalog/audit-pdf-dims.mjs    # dimension diff report
node scripts/catalog/audit-finishes.mjs    # finish name parity
npm run catalog:verify             # integrity (dims, codes, counts, no banned strings)
npm run catalog:images:verify      # real vs generated image counts
node scripts/catalog/build-image-coverage.mjs
```

## Out of scope (per branding decision)

Company name, phone `(208) 477-1169`, Meridian ID address/service area, the
deliberate stripping of "One Source"/"OSC"/"Reserve", and the linear-foot
estimate pricing model (`shared/estimateEngine.ts`) are intentionally unchanged.
