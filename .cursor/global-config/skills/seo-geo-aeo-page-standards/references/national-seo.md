# National / topical SEO build rules

Apply these on top of the universal core for any page aimed at a topic rather than a place: blog posts, pillar and cluster content, product and feature pages, comparisons, and resources. At national scale, the game is topical authority and entity clarity, and the main failure mode is publishing thin or templated pages that dilute authority.

## Topical authority and clusters

- Every page belongs to a defined topic cluster. Decide whether the new page is a pillar (broad, authoritative hub) or a supporting cluster page (specific subtopic) before writing.
- Pillar pages link to all their supporting pages and back. Build the silo as you create, not afterward, so authority concentrates instead of scattering.
- Cover the subtopic with real semantic depth. Surface-level posts do not build authority and are not cited by AI engines. Address the related questions, entities, and angles a reader and a model would expect on a page that owns this topic.

## Entity SEO

- Make the primary entity of the page explicit and connect it to the organization, brand, products, services, authors, and industry entities it relates to.
- Use consistent naming for entities across the site so engines resolve them to one thing rather than several.
- Where an authoritative external reference exists for an entity, link or reference it so the relationship is unambiguous.

## Programmatic and template pages

- If a page is generated from a template (feature, comparison, category, or data-driven pages), it must still clear the uniqueness bar. Template overuse produces near-duplicate, low-value pages that trigger doorway and thin-content problems at scale.
- For any programmatic set, calculate content and intent uniqueness. Flag and fix anything 70 percent or more similar to a sibling: rewrite for unique value, merge, redirect, or noindex.
- Each generated page must offer meaningful value independent of search, and contain information a user genuinely could not assemble themselves.

## Content depth and freshness

- Match and beat the depth of the pages currently ranking and being cited for the target intent, with original data, examples, or first-hand experience that competitors lack.
- Build in a path to keep the page current. Stale authority content loses both rankings and citations.

## National AEO and GEO

- Lead with a direct, self-contained answer and support it with definitions, steps, comparisons, and data tables that answer engines extract and cite.
- State facts as quotable, attributable sentences. Generative engines cite clear, confident, well-structured statements over hedged marketing copy.

## Competitor gap (quick pass before publishing)

Glance at what ranks and what AI engines cite for the target query. Confirm the new page closes a real gap in depth, structure, schema, entity coverage, or trust rather than adding another interchangeable result.

## National pre-publish additions

- [ ] Page is assigned as pillar or cluster, and the silo links both ways
- [ ] Real semantic depth, original substance, beats the current top results
- [ ] Primary entity explicit and consistently named, related entities connected
- [ ] If templated, passes the uniqueness bar and offers value beyond search
- [ ] Direct-answer plus extractable structures (definitions, steps, comparisons, data)
- [ ] Freshness path in place
- [ ] Closes a genuine competitor gap
