## 301 Redirect Strategy (.htaccess)

**CRITICAL:** Preserve all existing SEO value by implementing 301 redirects for ANY URLs that change or are restructured.

Example redirects needed:

```apache
# If old lawn aeration page moves
Redirect 301 /lawn-aeration/ /services/aeration.html

# If city pages restructure
Redirect 301 /boise/ /service-areas/boise.html

# Add redirect for EVERY page that changes URLs
```

**Instructions for Replit:**

- Analyze the current site structure from lawncarekuna.com
- Map every existing URL
- If ANY URL changes in the new structure, create a 301 redirect
- Redirects should point to the most relevant new page
- Preserve link equity and rankings
